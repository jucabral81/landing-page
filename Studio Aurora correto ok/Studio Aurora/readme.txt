# Studio Aurora: Landing Page para Autônomo

Projeto desenvolvido para a atividade de Produção Textual Individual (PTI)
da disciplina Fundamentos de Programação Web, Senac EAD.
Tema: Landing Page para Autônomo.

## Etapa A — Prototipação

Ramo de negócio escolhido: profissional autônoma de Design e Conteúdo
(Studio Aurora), atendendo pequenos negócios que precisam de identidade
visual e materiais para redes sociais.

Estrutura planejada antes da implementação (wireframe das faixas):

1. Cabeçalho fixo com logo e menu de navegação.
2. Hero: apresentação da marca, chamada principal e botões de ação.
3. Serviços: cards com as 3 soluções oferecidas.
4. Vantagens e benefícios: lista do porquê contratar o Studio Aurora.
5. Sobre: apresentação da profissional e destaque.
6. Contato: formulário (nome, e-mail, serviço, mensagem).
7. Rodapé: direitos autorais e link de retorno ao topo.


## Etapa B — Implementação

- HTML 
- CSS
- Layout com FlexBox (menu, hero, cards de serviço, lista de
  benefícios, seção sobre, formulário de contato e rodapé).
- Responsivo com media queries em 900px (tablet) e 700px (celular).
- Menu adaptado para telas pequenas (menu hambúrguer via CSS, com
  checkbox oculto controlando a exibição, sem uso de JS).
- Formulário de contato com campos de nome, e-mail, serviço e mensagem.

## Faixas
- Mais de 5 faixas/seções:
  1. Apresentação da empresa/hero;
  2. Serviços oferecidos;
  3. Vantagens e benefícios;
  4. Sobre a profissional;
  5. Contato com formulário;
  6. Rodapé.


## Netlify

1. Acesse o Netlify e faça login/crie sua conta.
2. Crie um novo site.
3. Envie a pasta do projeto ou o arquivo ZIP.
4. Após a publicação, copie o endereço gerado pelo Netlify.



### Formulário de contato no Netlify

O formulário foi configurado para usar o Netlify Forms, com processamento automático dos envios e redirecionamento para a página `obrigado.html` após o envio.
